Tu front-end va aquí

Esta página es web/index.html de tu proyecto Silence.

Desarrolla el front-end de tu aplicación (HTML, CSS y JavaScript) en la carpeta web/ del proyecto y sustituye esta página por la tuya. Silence sirve todo lo que pongas en esa carpeta en /: por ejemplo, web/css/estilos.css se sirve en /css/estilos.css.

Usar la API desde JavaScript

Tu front-end se comunica con la base de datos a través de la API de Silence, en la misma dirección que esta página: 

const respuesta = await fetch("/api/v1/departments");
const departamentos = await respuesta.json();
